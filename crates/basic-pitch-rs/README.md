Polyphonic audio-to-MIDI transcription with pitch bends, in Rust: an unofficial,
parity-tested port of Spotify's [Basic Pitch](https://github.com/spotify/basic-pitch).
It runs the official model with [tract](https://github.com/sonos/tract) (pure Rust, also
on `wasm32-unknown-unknown`) or ONNX Runtime, and reproduces the Python post-processing
note for note.

![The contour posteriorgram of a 10 s synthetic guitar recording in gray, with the 18 notes basic-pitch-rs detects and their pitch bends drawn in green over it.](https://raw.githubusercontent.com/AThevon/basic-pitch-rs/main/assets/hero.svg)

## Usage

```toml
[dependencies]
basic-pitch-rs = "0.1"
```

The crate is imported as `basic_pitch`.

```rust
use basic_pitch::{BasicPitch, NoteParams};

fn main() -> Result<(), basic_pitch::Error> {
    // Mono samples at 22 050 Hz: decode and resample your audio first.
    // Here, two seconds of A4 (440 Hz).
    let audio: Vec<f32> = (0..44_100)
        .map(|i| 0.5 * (2.0 * std::f32::consts::PI * 440.0 * i as f32 / 22_050.0).sin())
        .collect();

    let transcriber = BasicPitch::new()?; // loads the bundled model once
    let transcription = transcriber.transcribe(&audio)?;

    for note in transcription.sorted_notes() {
        println!(
            "{:.3} s to {:.3} s  MIDI {}  velocity {}",
            note.start_s, note.end_s, note.pitch, note.velocity()
        );
    }

    let midi: Vec<u8> = transcription.to_midi(&Default::default())?; // a Standard MIDI File

    // Decode the notes again with other parameters, without running the model.
    let centered = transcription.decode_notes(&NoteParams {
        onset_threshold: 0.6,
        bend_offset: -1, // centers the pitch bends of in-tune notes on 0
        ..NoteParams::default()
    })?;
    println!("MIDI file: {} bytes, notes with centered bends: {}", midi.len(), centered.len());
    Ok(())
}
```

The library takes samples, not files. The
[`transcribe_file`](https://github.com/AThevon/basic-pitch-rs/blob/main/crates/basic-pitch-rs/examples/transcribe_file.rs)
example reads a WAV file, and the
[`basic-pitch-cli`](https://crates.io/crates/basic-pitch-cli) crate is a complete
command-line tool (WAV, AIFF, CAF, FLAC, MP3, Ogg, M4A, MOV).

Every step of the pipeline is public: windowing, inference through the `Backend` trait
(plug in your own runtime), unwrapping, note decoding and MIDI export.
`BasicPitch` is `Send + Sync`, and `BasicPitch::with_threads` spreads the model windows
over several cores with bit-identical results.

## Features

| Feature | Default | Description |
| --- | --- | --- |
| `tract` | yes | Pure Rust inference with tract; works on `wasm32-unknown-unknown` |
| `bundled-model` | yes | Embeds the official `nmp.onnx` (230 kB) |
| `midi` | yes | Standard MIDI File export, with the events of Basic Pitch's pretty_midi output |
| `ort` | no | ONNX Runtime backend, about 3 times faster per window natively. Links an ONNX Runtime 1.31 that you provide; requires Rust 1.92 |
| `ort-download` | no | `ort`, with a prebuilt ONNX Runtime downloaded at build time |
| `serde` | no | `Serialize` and `Deserialize` on the public types |

## Parity with Python

Checked against fixtures generated by basic-pitch 0.4.0 (ONNX model, onnxruntime on the
CPU) and by its `main` branch, on 6 recordings, 8 parameter sets and 2 trim modes:

- audio windows, unwrapped outputs and frame times: bit-identical;
- model outputs: within 1.3e-6 of onnxruntime with tract, bit-identical with `ort`;
- notes from the same model outputs: 1650 of 1650 identical, with their frames, times,
  amplitudes and about 21 000 pitch bend values; MIDI files: identical events;
- whole pipeline with tract, from samples to notes: 1650 of 1650 notes identical.

The defaults reproduce Python, including its +1/3 semitone pitch bend on in-tune notes
([spotify/basic-pitch#87](https://github.com/spotify/basic-pitch/issues/87)), which
`NoteParams::bend_offset = -1` compensates. The default `TrimMode::Main` keeps the end of
each file, like upstream `main`; `TrimMode::V0_4_0` reproduces the PyPI release.

## WebAssembly

```sh
cargo build --target wasm32-unknown-unknown --no-default-features --features tract,bundled-model
```

No extra flag is needed. tract's WebAssembly kernels do not use fused multiply-add, so
the model outputs differ from Python by up to 5e-4 instead of 1e-6; on the test
recordings, 824 of 825 notes stay identical. The repository has
[`wasm-bindgen` bindings and a browser demo](https://github.com/AThevon/basic-pitch-rs/tree/main/examples/wasm).
