## [0.1.0] - 2026-10-17

### Added

- Rust port of the Basic Pitch inference and note creation pipeline from
  spotify/basic-pitch v0.4.0: audio windowing, model inference, output unwrapping,
  note events, pitch bends and Standard MIDI File export.
- The Basic Pitch ONNX model (`nmp.onnx`, unmodified from spotify/basic-pitch
  v0.4.0), bundled behind the default `bundled-model` feature.
- Pure Rust inference with tract (default `tract` feature), which also builds for
  `wasm32-unknown-unknown`.
- Optional ONNX Runtime backend (`ort` feature), forced onto the CPU execution
  provider so that its output matches the reference. The `ort-download` feature
  also downloads a prebuilt ONNX Runtime at build time; `ort` alone links the one
  you provide. The `ort` crate is re-exported as `basic_pitch::ort`.
- `BasicPitch::with_threads` and `model::run_inference_parallel`: the model
  windows run on several threads, with results identical to a single thread.
- `TrimMode` implements `Display` and `FromStr`, and serializes as `"main"` or
  `"v0.4.0"`.
- Both output trim modes: the one of the v0.4.0 release, and the one of upstream
  main, which no longer drops the end of the file (the default).
- `bend_offset` option to correct the known +1 bin bias of pitch bends
  (spotify/basic-pitch#87). The default of 0 keeps parity with upstream.
- Optional `serde` support for the public data types (`serde` feature).
- `basic-pitch-rs` command-line tool (crate `basic-pitch-cli`): MIDI, JSON
  (with a JSON Schema), CSV and NumPy outputs, the options of the Python tool,
  gapless decoding of AAC in MP4, M4A, MOV and CAF, and one thread per core.
- Parity test suite against fixtures generated by the official Python
  implementation (ONNX backend), at every stage of the pipeline, plus
  adversarial post-processing cases.

### Differences with Python

- A negative `frame_threshold` is rejected: the Python melodia loop never ends
  with it.
- Notes that cannot be written to a MIDI file (amplitude outside `[0, 1]` after
  rounding, NaN, pitch above 127) make the MIDI export fail, like Python does
  when it writes the file, instead of being clamped.
- The command-line tool ignores a `--minimum-frequency` below A0 (27.5 Hz) with
  a warning, where Python turns it into a negative index and drops nearly every
  note.
